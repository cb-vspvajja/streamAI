How the search modes work

FTSField-aware lexical matching across title, synopsis, genres, keywords and people. Best for exact words, names and filters.

VectorEmbeds the query and retrieves semantically similar catalogue embeddings. Best for themes, mood and conceptual language.

HybridSends both a regular Search query and a KNN vector query to Couchbase. Matches from either route can qualify; titles strong in both rank higher.

Structured shortcutKnown genres, countries and profile signals skip embedding and use deterministic FTS/SQL++ for lower latency and exactness. The trace shows requested and effective modes.
