# Search index deployment

The runtime queries the scoped index named by `CATALOGUE_SEARCH_INDEX` through the Couchbase SDK when `SEARCH_TRANSPORT=sdk`.

For local Docker, `tools/load_catalogue.py` creates the index automatically. For an existing Enterprise cluster or Capella, load the catalogue, determine the vector length with:

```sql
SELECT RAW ARRAY_LENGTH(t.embedding)
FROM `streaming`.`catalogue`.`titles` AS t
WHERE t.embedding IS NOT MISSING
LIMIT 1;
```

Create/import the same scoped index definition generated by `tools/load_catalogue.py`, setting the `embedding` vector dimensions to that value. Never mix vectors from different models in one index.
