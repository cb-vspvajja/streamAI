# TMDB Attribution

This product uses the TMDB API but is not endorsed or certified by TMDB.

The StreamAI demo retrieves metadata and artwork paths at runtime from The Movie Database (TMDB). The package does not redistribute TMDB poster or backdrop image files.

Before external or commercial use, review the current TMDB API terms and branding requirements:

- https://developer.themoviedb.org/docs/faq
- https://www.themoviedb.org/settings/api
